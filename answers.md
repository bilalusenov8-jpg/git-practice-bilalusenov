# Ответы на вопросы задания

1. Папку venv не коммитят: она содержит локальные файлы интерпретатора и установленных пакетов, занимает место и зависит от ОС и версии Python.

2. После клонирования разработчик создаёт окружение командой `python -m venv venv`, активирует его и устанавливает зависимости командой `pip install -r requirements.txt`.

3. requirements.txt перечисляет зависимости проекта, чтобы их можно было установить в новом окружении. В `.gitignore` исключают само окружение (`venv/`), но не файл `requirements.txt` — его нужно хранить в Git.
